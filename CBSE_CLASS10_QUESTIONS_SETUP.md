```
2. Questions are retrieved from pool for that subject

5. RESULT: 3 random basic-level questions
```

### Adding More Questions

To add more basic CBSE Class 10 questions:

1. **Edit** `scripts/parse-pdf-questions.js`
2. **Add new questions** in the `customQuestions` object with:
   - `difficulty: "Easy"` (for questions 1-3)
   - `exam: "CBSE Class 10"`
   - Ensure questions are genuinely basic level
3. **Run** `node scripts/parse-pdf-questions.js`
4. **Verify** with: `cat data/question-bank.json | grep -c '"difficulty":"Easy"'`
